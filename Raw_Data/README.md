# Last-Mile Delivery Performance and Operations Analytics

## Dataset Information

This project uses the **LaDe (Last-mile Delivery Dataset)**, a publicly available industry-scale last-mile delivery dataset.

### 1. LaDe: Last-mile Delivery Dataset

Dataset Source: <https://huggingface.co/datasets/Cainiao-AI/LaDe/tree/main/delivery>

Research Paper: <https://arxiv.org/abs/2306.10675>

Download the dataset and place the downloaded files in the `Raw_Data/` folder.
